# History

**History** records what happened in the library, newest first: items added
and removed, downloads, imports and file changes. Each series and movie page
has the same list for that item.

Entries are grouped by day with their time. **Show older** loads the next 50.
An entry about several files folds them under **Show N files**.

## Entries

| Entry | When |
|---|---|
| Added series / movie | You added an item |
| Removed series / movie | You removed an item; *and its files* when they were deleted too |
| Added torrent | A torrent was added for an item, by you or picked up from Transmission |
| Finished downloading | Transmission finished a torrent |
| Imported | Files from a download were placed in the library |
| An import needs review | Some files couldn't be matched; see the [Queue](./queue.md) |
| An import failed | The import stopped with the reason shown |
| Found | A scan linked files already in an item's folder |
| Deleted | A file was deleted: *gone from disk*, *replaced by an import*, *by request* or *its item was removed* |
| Renamed | Files were renamed to the naming patterns, with old and new paths |
| Renumbered | A series' episode numbering changed, so its files were matched again |
| Removed torrent … after seeding | The torrent finished seeding and was removed from Transmission |
| Changed setting | A setting was changed |

An item that's been removed keeps its name in the entries, without a link.
